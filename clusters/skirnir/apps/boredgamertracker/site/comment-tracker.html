Comment verification (API) edit ▾

Checks YouTube's public comments on a video for a comment from your channel — this reads public data, no login needed. Requires a free YouTube Data API v3 key from Google Cloud Console ↗ (enable "YouTube Data API v3", create an API key). Enter it below once — "Save settings" keeps it in this browser only; "Save to server" (password-protected) stores it on the server so it's pre-filled on every device.

Your comment lines edit ▾

One line per comment. When you hit "Comment" on a video, a random line from this list is copied to your clipboard — you paste it into YouTube yourself. Personalize these so they don't read like a bot loop.

Video database toggle ▾

Videos are read from videos.yaml, a file next to this page on your server that fetch_videos.py keeps in sync. That script merges in new uploads and never deletes old ones, so a video stays here even after it drops off YouTube's "15 most recent" feed. Run the script once to create the file, then schedule it (cron, every 30 min or so) to keep it current.

If videos.yaml is missing or the fetch above fails, you can paste feed content below as a one-off, browser-only preview — it won't touch the file on the server, so run the script to make it permanent.
